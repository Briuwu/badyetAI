# Badyet AI

**Smart. Simple. Personalized. Your AI-Powered Financial Sidekick.**

![Badyet AI Logo](https://placeholder.com/preview.png)

## Overview

Badyet AI is an intelligent personal finance tracker that makes budgeting and saving effortless. Built for simplicity and powered by AI, Badyet helps users take control of their finances through intuitive natural language inputs, personalized insights, and real-time tracking. Whether you're looking to save more, spend smarter, or plan for your future, Badyet helps you reach your financial goals—faster and smarter.

## 🔍 Core Features

- **AI Budget Creation via Natural Language:** Just tell Badyet what you need:
  "Help me build a monthly budget for $3,000 income with $1,000 rent and weekly groceries." Badyet AI instantly builds a smart, balanced budget tailored to your needs.

- **Smart Expense Categorization:** Automatically categorize your spending based on transaction descriptions and behavior—no need to tag every purchase manually.

- **Personalized Recommendations:** Powered by Mistral AI, Badyet learns your spending habits and offers personalized advice to help you save more, avoid overspending, and reach financial milestones.

- **Goal-Based Budgeting:** Create budgets with specific goals like "Save $5,000 for a vacation by December," and let Badyet guide your monthly spending to make it happen.

- **Conversational Finance Help (AI Assistant):** Chat with your finances:
  "Why did I spend more this month?" "How can I reduce my food expenses next month?" The AI assistant gives clear, data-driven answers, instantly.

## ⚙️ Tech Stack

- **Frontend:** Next.js 15, TailwindCSS, shadcn/ui components
- **Backend:** Supabase for database, authentication, and serverless functions
- **AI Integration:** Vercel AI SDK, Mistral AI for LLM capabilities
- **Deployment:** Vercel for hosting and CI/CD

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn
- Supabase account
- Mistral AI API key

### Installation

1. Clone the repository:

   ```
   git clone https://github.com/yourusername/badyet-ai.git
   cd badyet-ai
   ```

2. Install dependencies:

   ```
   npm install
   # or
   yarn install
   ```

3. Set up environment variables:

   ```
   cp .env.example .env.local
   ```

   Then edit `.env.local` to add your API keys and configuration.

4. Run the development server:

   ```
   npm run dev
   # or
   yarn dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
